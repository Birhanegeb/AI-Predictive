# Predictive Maintenance - EDA, Preprocessing & Classification

Predicts machine failure (`Target`: 1 = fail, 0 = not fail) and failure type
from a synthetic industrial sensor dataset, covering EDA, preprocessing, and
several classification models (Decision Tree, Random Forest, Bagging,
BalancedBagging, KNN, MLP).

## Step-by-step setup

### 1. Clone the repo and create a virtual environment

```bash
git clone https://github.com/Birhanegeb/AI-Predictive
cd AI-Predictive
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```
### 3. Launch Jupyter

```bash
jupyter notebook Predictive_maintenance.ipynb
```

### 4. Run all cells top to bottom

`Kernel → Restart & Run All`. Order matters — later cells (encoding, scaling,
model training) depend on dataframes created earlier (`df`, `df_winsor`,
`df_encoded`, `df_final`, `X`, `y`, `X_train`, etc.), so don't skip around.

An `assets/` folder is created automatically by the second code cell
(`os.makedirs('assets', exist_ok=True)`). Every chart in the notebook now
saves a copy into `assets/` right before it's displayed — nothing extra to
run. See the full list below.

## What gets saved to `assets/`

Because of notbook sisze is large, Girhub can not display the image outputs for every cell. It either make the notebook invalid or invisible, to solve this all visualization figures from EDA to Data processing are saved to /assets. Models are saved in /models 
## Pipeline overview

1. **EDA** — shape, dtypes, missing values, duplicates, univariate and
   multivariate analysis (bar/pie/box/histogram/heatmap/pair plot/bubble chart)
2. **Outlier detection** — Z-score and Isolation Forest
3. **Outlier handling** — Winsorization on `Rotational speed`, `Torque`, `Tool wear`
4. **Encoding** — ordinal for `Type`, one-hot for `Failure Type`; `Product ID`/`UDI` dropped
5. **Scaling** — `RobustScaler` (chosen for robustness to remaining outliers)
6. **Class imbalance** — `BalancedBaggingClassifier` / class weights (no over/undersampling)
7. **Modeling** — Decision Tree, Random Forest, Bagging, KNN, MLP; confusion
   matrices, feature importance, decision boundaries, ROC curves
